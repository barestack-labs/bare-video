Beginner setup

One video. One folder.

Keep the source video, references, repo, secrets, temporary files, and output together. It makes cleanup and agent handoffs much less stupid.

my-video/
├── input/
│   └── video.mp4
├── references/
├── assets/
├── bare-video/
├── .env
├── runtime/
├── workspace/
└── output/
1

Create the project folder and put the raw video in input/.

2

Open Bare Video on GitHub ↗ and clone/download it into bare-video/.

3

Generate your prompt on this page and paste it into your coding agent.

4

If cloud transcription needs a key, the agent creates and opens .env. Paste the key there, not into chat.

5

Review the browser preview before export.

Experienced user? Put the repo wherever you want. You can also keep the Bare Video skill in your agent's supported user-level skills folder for repeated use.
