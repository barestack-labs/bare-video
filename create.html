6 · First output

What should the agent give you first?

A preview is the safer default. You can react in plain language, then the agent fixes the edit before final export.

HyperFrames is optional.

After the transcript and plan, the agent checks whether FFmpeg alone is enough. If HyperFrames would genuinely help and it is not already available in this video folder, the agent asks before adding it locally. No global install by default.
