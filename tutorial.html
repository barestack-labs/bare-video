Edit your first video with Bare Video

This is the whole thing from zero, so even if you've never opened a terminal before you can follow it. The setup takes around 20 minutes the first time, and after that every new video is basically just dropping a file into a folder and pasting one message.

What you'll end up with

You give the agent a video of you talking to the camera, and it gives you back a vertical 1080x1920 video with the boring parts cut out, captions that light up word by word, and simple graphics like titles, lists and numbers that show up when you say them. You watch a preview in your browser first, ask for changes in normal words, and only then does it export.

Everything runs on your own computer. The only thing that leaves it is a small audio file that gets sent for the transcript.

Install the tools

You need three free tools. If you already have them, you can skip this part, and if you're not sure, your agent will check for you later anyway.

On Windows

Open PowerShell (press the Windows key, type PowerShell, press Enter) and paste these one at a time:

winget install OpenJS.NodeJS.LTS
winget install Gyan.FFmpeg
winget install Git.Git

Close PowerShell and open it again after installing, otherwise it won't find the new tools yet.

On a Mac

Open Terminal. If you don't have Homebrew yet, install it from brew.sh first, then:

brew install node ffmpeg git

Check that it worked

node --version
ffmpeg -version
git --version

Node needs to say v22 or higher. If one of them says "not recognized" or "command not found", install that one again and reopen the terminal.

Pick your AI agent

Bare Video works with any coding agent that can read files and run commands. Here's how they compare, and honestly you can start with the free one and switch later.

Claude CodePaid planThe smoothest, even the small Haiku model edits a video in a few minutes.

The free route with OpenCode

Install OpenCode:

npm install -g opencode-ai

OpenCode comes with its own free models, but they have a daily limit that runs out fast on busy days. A steadier free option is Kilo Gateway, which has free models like Nemotron. Make a free account at kilo.ai, copy your API key, and put this in a file called opencode.json inside your videos folder (you'll make that folder in the next step):

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "kilo": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Kilo Gateway",
      "options": {
        "baseURL": "https://api.kilo.ai/api/gateway",
        "apiKey": "{env:KILOCODE_API_KEY}"
      },
      "models": {
        "nvidia/nemotron-3-ultra-550b-a55b:free": { "name": "Nemotron 3 Ultra (free)" }
      }
    }
  }
}

Then save your Kilo key once so OpenCode can find it. On Windows, in PowerShell:

setx KILOCODE_API_KEY "paste-your-kilo-key-here"

On a Mac, run echo 'export KILOCODE_API_KEY="paste-your-kilo-key-here"' >> ~/.zshrc. Close and reopen the terminal either way, then start OpenCode in your videos folder and pick the Nemotron model with /models.

Free models change all the time, so if one stops working, try another free one from the same list. Groq's free chat models don't work for this, because their free limit is smaller than what an agent sends in one go.

Make your videos folder

This is the part that keeps things tidy and saves you storage. You make one folder for all your videos, install the editing tools in it once, and then every video gets its own small folder inside.

mkdir videos
cd videos
git clone --depth 1 https://github.com/barestack-labs/bare-video
npm install hyperframes
npx hyperframes browser ensure

That last part downloads HyperFrames and the browser it renders with, which is around 250 MB, but you only do it once for all your videos. Your folder ends up looking like this:

videos/
  bare-video/       the skill
  node_modules/     HyperFrames, shared by every video
  .env              your keys (next step)
  car-review/       one folder per video
    source.mp4
    assets/         your own images or clips, if you have any

Don't put the videos folder inside Google Drive, OneDrive or Dropbox. They try to sync thousands of tiny files from node_modules and every temporary render, and it gets slow and messy really fast.

Get a free Groq key

Groq turns your speech into text with the exact time of every word, and the free tier is more than enough.

  1. Go to console.groq.com and sign up.
  2. Open API Keys and create a key, then copy it.
  3. In your videos folder, make a file called .env and put this in it, with your key after the equals sign:
GROQ_API_KEY=your-key-here

Never paste your keys into the chat with the agent. If the agent needs a key and can't find it, it'll open the .env file for you so you can paste it there yourself.

Want to skip Groq?

You can transcribe on your own computer instead by telling the agent "use local transcription". It's slower and the first time needs a big download, so I'd only do that if you don't want any audio leaving your computer.

Record your video

Bare Video is made for one person talking to the camera, so a few small things make a big difference:

  • Film vertical on your phone, or on a webcam, with your face around the upper middle of the frame.
  • Say the names of things clearly, especially brands and websites, because those are the words that get misheard most.
  • Don't worry about mistakes. If you mess up a sentence, just pause and say it again, and the agent keeps the last clean take.
  • Got photos or clips you want to show, like the car, the food or the app? Put them in an assets folder next to your video and mention them to the agent.

Make a folder for the video inside videos, like videos/car-review, and put the video file in it.

Let the agent edit it

Open your agent inside the videos folder. In Claude Code or OpenCode, that means opening the terminal in that folder and typing claude or opencode. Then paste this, with your video's path at the end:

Edit my video with Bare Video.
1. If there is no bare-video folder here, run:
   git clone --depth 1 https://github.com/barestack-labs/bare-video
2. Read bare-video/SKILL.md and follow its steps in order.

My video: car-review/source.mp4

The agent will ask you a few things in one message, which are what the video is about, how long you want it, which look you like (daylight, graphite, paper or loud) and what kind of captions. Answer however you want, even "you pick" is fine.

Then it works on its own. It transcribes, picks your best takes, cuts out the pauses, plans the titles and lists, checks its own plan, and builds a preview. In my tests on a 4-minute recording, Claude Haiku took about 3 minutes and the free Nemotron models took 6 to 9 minutes, and you can see what each of them made on the homepage.

Ask for changes

When it's done it gives you a preview link. Open it, watch it, and just tell the agent what you think, the same way you'd tell a friend who's editing for you. For example:

  • "Cut the part where I talk about the price, it's too long."
  • "Make the first title bigger news, like 'This car shocked me'."
  • "Use my brand color #e63946 instead of the blue."
  • "Show the interior photo when I say 'look at this'."
  • "Captions are too much, make them calmer."

It only changes what you asked for, so you can go back and forth as many times as you want before anything gets exported.

Export and clean up

When you're happy, tell it to export. It renders the video, sets the loudness so it doesn't sound quiet on TikTok or Reels, checks the file, and puts final.mp4 in your video's folder. On a normal laptop a one-minute video takes a few minutes to render.

Then it asks if you want to delete the temporary files. Say yes unless you're still planning to edit, because those can be a few hundred MB. It keeps your original video, your final video, and a few tiny text files with the plan, so you can still re-make the edit later without starting over.

If something goes wrong

Most of the time the agent fixes it by itself, because every script says exactly what went wrong and how to fix it. If you're stuck, these are the usual ones:

  • "ffmpeg could not start" or "node is not recognized" means a tool isn't installed or the terminal needs to be reopened.
  • "no transcription key found" means the .env file is missing or in the wrong folder. It goes in videos, not inside bare-video.
  • The model stops halfway or says it hit a limit means the free model ran out for the day, so switch to another free model or try again later.
  • Text covers your face, just tell the agent "move the graphics so they don't cover my face".

There's a longer list in the troubleshooting doc. And if you want your own editing style or a setup like this built for you, message me at hello@paulablaza.com.
