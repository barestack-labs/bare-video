Edit your first video with Bare Video

Are you a beginner? Then this page is for you. It goes from zero to a finished video, so even if you've never opened a terminal before you can just scroll and follow along. The first time takes around 20 minutes, and after that every new video is basically recording, dropping the file in a folder, and pasting one message.

Everything here is free. The AI agent is Kilo CLI with its free models, so you don't need a paid plan or even an account for the agent.

1. Record your video

Bare Video is made for one person talking to the camera, so reviews, recipes, tips, tutorials, workouts and stories. A few small things make a big difference:

  • Film vertical on your phone, or on a webcam, with your face around the upper middle of the frame.
  • Say the names of things clearly, especially brands and websites, because those are the words that get misheard most.
  • Don't worry about mistakes. If you mess up a sentence, just pause and say it again, and the agent keeps the last clean take.
  • Got photos or clips you want to show, like the car, the food or the app? Keep them, you'll put them next to the video in step 4.

Then copy the video file to your computer. Any normal format works, like .mp4 or .mov.

2. Install the tools

You need three free tools. If you already have them, you can skip this part.

On Windows

Open PowerShell (press the Windows key, type PowerShell, press Enter) and paste these one at a time:

winget install OpenJS.NodeJS.LTS
winget install Gyan.FFmpeg
winget install Git.Git

Close PowerShell and open it again after installing, otherwise it won't find the new tools yet.

On a Mac

Open Terminal. If you don't have Homebrew yet, install it from brew.sh first, then:

brew install node ffmpeg git

Check that it worked

node --version
ffmpeg -version
git --version

Node needs to say v22 or higher. If one of them says "not recognized" or "command not found", install that one again and reopen the terminal.

3. Install Kilo CLI

Kilo CLI is the AI agent that does the editing. It runs in your terminal and it comes with free models that work right away, with no account and no key.

npm install -g @kilocode/cli

Check it with kilo --version. That's it for the agent.

The free model I'd pick is Nemotron 3 Ultra. In my test it edited a 4-minute video into a 59-second short in about 6 minutes, and you can watch the result on the homepage. Free models come and go, so if one stops working, just pick another one ending in ":free".

4. Make your videos folder

This is the part that keeps things tidy and saves you storage. You make one folder for all your videos, install the editing tools in it once, and then every video gets its own small folder inside.

mkdir videos
cd videos
git clone --depth 1 https://github.com/barestack-labs/bare-video
npm install hyperframes
npx hyperframes browser ensure

That downloads HyperFrames and the browser it renders with, which is around 250 MB, but you only do it once for all your videos. Now make a folder for your video, like videos/car-review, and put the video you recorded in it. If you have photos or clips to show, put them in an assets folder next to it:

videos/
  bare-video/       the skill
  node_modules/     HyperFrames, shared by every video
  .env              your Groq key (next step)
  car-review/       one folder per video
    source.mp4      the video you recorded
    assets/         your own photos or clips, if you have any

Don't put the videos folder inside Google Drive, OneDrive or Dropbox. They try to sync thousands of tiny files and every temporary render, and it gets slow and messy really fast.

5. Get a free Groq key

Groq turns your speech into text with the exact time of every word, and the free tier is more than enough.

  1. Go to console.groq.com and sign up.
  2. Open API Keys and create a key, then copy it.
  3. In your videos folder, make a file called .env and put this in it, with your key after the equals sign:
GROQ_API_KEY=your-key-here

Never paste your key into the chat with the agent. If the agent can't find it, it'll open the .env file so you can paste it there yourself.

6. Let the agent edit it

Open your terminal in the videos folder and start Kilo:

cd videos
kilo

Type /models, pick Nemotron 3 Ultra (free), then paste this message with your video's path at the end:

Edit my video with Bare Video.
1. If there is no bare-video folder here, run:
   git clone --depth 1 https://github.com/barestack-labs/bare-video
2. Read bare-video/SKILL.md and follow its steps in order.

My video: car-review/source.mp4

The agent asks you a few things in one message, which are what the video is about, how long you want it, which look you like (daylight, graphite, paper or loud) and what kind of captions. Answer however you want, even "you pick" is fine. When it asks to run a command, you can allow it.

Then it works on its own. It transcribes, picks your best takes, cuts out the pauses, plans the titles and lists, checks its own plan, and builds a preview. With the free model this takes around 5 to 10 minutes, so you can grab a coffee.

7. Ask for changes

When it's done it gives you a preview link. Open it, watch it, and just tell the agent what you think, the same way you'd tell a friend who's editing for you. For example:

  • "Cut the part where I talk about the price, it's too long."
  • "Make the first title stronger, like 'This car shocked me'."
  • "Use my brand colour #e63946 instead of the blue."
  • "Show the interior photo when I say 'look at this'."
  • "The captions are too much, make them calmer."

It only changes what you asked for, so you can go back and forth as many times as you want before anything gets exported.

8. Export and clean up

When you're happy, tell it to export. It renders the video, sets the loudness so it doesn't sound quiet on TikTok or Reels, checks the file, and puts final.mp4 in your video's folder. On a normal laptop a one-minute video takes a few minutes to render.

Then it asks if you want to delete the temporary files. Say yes unless you're still planning to edit, because those can be a few hundred MB. It keeps your original video, your final video, and a few tiny text files with the plan, so you can still re-make the edit later.

For your next video, you just make a new folder inside videos, drop the file in, start kilo and paste the message again.

Using another agent

Already pay for Claude Code or Codex? The same message works there too, just open it in your videos folder and paste it. In my test the small Claude Haiku model did the whole edit in about 3 minutes. Any agent that can read files and run commands can do it.

If something goes wrong

Most of the time the agent fixes it by itself, because every script says exactly what went wrong and how to fix it. If you're stuck, these are the usual ones:

  • "ffmpeg could not start" or "node is not recognized" means a tool isn't installed or the terminal needs to be reopened.
  • "no transcription key found" means the .env file is missing or in the wrong folder. It goes in videos, not inside bare-video.
  • The model stops halfway or says it hit a limit means the free model is busy, so pick another free model with /models and say "continue".
  • Text covers your face, just tell the agent "move the graphics so they don't cover my face".

There's a longer list in the troubleshooting doc. And if you want your own editing style or a setup like this built for you, message me at hello@paulablaza.com or check out paulablaza.com.
