Let your agent set it up

If you already have any AI agent that can run commands, this is honestly the easiest way. You give it this page, and it reads the steps, checks what you already have, asks before installing anything, and asks you the questions it needs, like which video and which look.

Go to https://shorts.paulablaza.com/tutorial and set up Bare Video for me.
Follow the steps there, check what I already have, ask me before
installing anything, and ask me questions when you need to.
Then edit my video with it.

Don't have an agent yet? The steps below set up a free one.

1. Record your video

Bare Video is made for one person talking to the camera, so reviews, recipes, tips, tutorials, workouts and stories. A few small things make a big difference:

  • Film vertical on your phone, or on a webcam, with your face around the upper middle of the frame.
  • Say the names of things clearly, especially brands and websites, because those are the words that get misheard most.
  • Don't worry about mistakes. If you mess up a sentence, just pause and say it again, and the agent keeps the last clean take.
  • Got photos or clips you want to show, like the car, the food or the app? Keep them, they go next to the video in step 4.

2. Install the tools

You need three free tools. If you already have them, skip this part.

On Windows

Open PowerShell (press the Windows key, type PowerShell, press Enter) and paste these one at a time:

winget install OpenJS.NodeJS.LTS
winget install Gyan.FFmpeg
winget install Git.Git

Close PowerShell and open it again after installing, otherwise it won't find the new tools yet.

On a Mac

Open Terminal. If you don't have Homebrew yet, install it from brew.sh first, then:

brew install node ffmpeg git

Check that it worked

node --version
ffmpeg -version
git --version

Node needs to say v22 or higher. If one of them says "not recognized" or "command not found", install that one again and reopen the terminal.

3. Get a free AI agent

The agent is the thing that actually does the editing. I tested this with Kilo CLI and its free models, and it works with no account and no key:

npm install -g @kilocode/cli

The free model I'd pick is Nemotron 3 Ultra. It edited my 4-minute video into a 59-second short in about 6 minutes, and you can watch it on the homepage. The same free models also work in Hermes Agent, OpenCode or any agent that supports Kilo, and if one model is busy, just pick another one ending in ":free".

Already paying for Claude Code or Codex? Those work too, and in my test the small Claude Haiku model did the whole edit in about 3 minutes.

4. Make your videos folder

This is the part that keeps things tidy and saves you storage. You make one folder for all your videos, install the editing tools in it once, and then every video gets its own small folder inside.

mkdir videos
cd videos
git clone --depth 1 https://github.com/barestack-labs/bare-video
npm install hyperframes
npx hyperframes browser ensure

That downloads HyperFrames and the browser it renders with, around 250 MB, but only once for all your videos. Then for each video you make a folder and drop the file in, and the agent fills in the rest:

videos/
bare-video/ the skill
node_modules/ HyperFrames, shared
.env your Groq key
car-review/ you make this
source.mp4 you drop this in
edit/ the agent's plan, tiny text files
work/ temporary, deleted at the end
final.mp4 your finished short

Don't put the videos folder inside Google Drive, OneDrive or Dropbox. They try to sync thousands of tiny files and every temporary render, and it gets slow and messy fast.

5. Get a free Groq key

Groq turns your speech into text with the exact time of every word, and the free tier is more than enough.

  1. Go to console.groq.com and sign up.
  2. Open API Keys, create a key and copy it.
  3. In your videos folder, make a file called .env with this line, your key after the equals sign:
GROQ_API_KEY=your-key-here

Never paste your key into the chat with the agent. If the agent can't find it, it opens the .env file so you can paste it there yourself.

6. Let the agent edit it

Open your terminal in the videos folder and start Kilo with kilo. Type /models, pick Nemotron 3 Ultra (free), then paste this with your video's path at the end:

Edit my video with Bare Video.
1. If there is no bare-video folder here, run:
   git clone --depth 1 https://github.com/barestack-labs/bare-video
2. Read bare-video/SKILL.md and follow its steps in order.

My video: car-review/source.mp4

The agent asks a few things in one message: what the video is about, how long you want it, which look (daylight, graphite, paper or loud) and what kind of captions. Even "you pick" is fine. When it asks to run a command, you can allow it.

Then it works on its own. It transcribes, picks your best takes, cuts out the pauses, plans the titles and lists, checks its own plan and builds a preview. With a free model this takes around 5 to 10 minutes.

7. Ask for changes

When it's done it gives you a preview link. Watch it and just tell the agent what you think, the same way you'd tell a friend who's editing for you:

  • "Cut the part where I talk about the price, it's too long."
  • "Make the first title stronger, like 'This car shocked me'."
  • "Use my brand colour #e63946 instead of the blue."
  • "Show the interior photo when I say 'look at this'."
  • "The captions are too much, make them calmer."

It only changes what you asked for, so you can go back and forth as much as you want before anything gets exported.

8. Export and clean up

When you're happy, tell it to export. It renders the video, sets the loudness so it doesn't sound quiet on TikTok or Reels, checks the file, and puts final.mp4 in your video's folder.

Then it asks if you want to delete the temporary files. Say yes unless you're still editing, because those can be a few hundred MB. Your original, your final video and the tiny plan files stay, so you can still re-make the edit later. For your next video, you just make a new folder, drop the file in, and paste the message again.

If something goes wrong

Most of the time the agent fixes it by itself, because every script says exactly what went wrong and how to fix it. The usual ones:

  • "ffmpeg could not start" or "node is not recognized" means a tool isn't installed or the terminal needs reopening.
  • "no transcription key found" means the .env file is missing or in the wrong folder. It goes in videos, not inside bare-video.
  • The model stops halfway or hits a limit means the free model is busy, so pick another free one with /models and say "continue".
  • Text covers your face, just say "move the graphics so they don't cover my face".

There's a longer list in the troubleshooting doc. And if you want your own editing style or a setup like this made for you, message me at hello@paulablaza.com or visit paulablaza.com.
