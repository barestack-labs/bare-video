# Reference grammar

The first Bare Default language was informed by user-provided short-form reference videos. The repository does not redistribute those reference videos or copy third-party brand assets.

Common patterns distilled into Bare Default:

- full-screen speaker as the stable baseline
- top/bottom split for tutorial proof
- short editorial takeovers for steps, stats and payoffs
- real screenshots and demos before generic cards
- restrained warm palette with strong black/white contrast and yellow emphasis
- large whitespace and clean hierarchy
- layout changes as the primary stimulation, not constant zooming
- SFX attached to meaningful visual events
- captions move with layout state
